Installation

Three.js is a peer dependency — install it alongside rack3d-visualizer.

NPM / Yarn

# npm
npm install rack3d-visualizer three

# yarn
yarn add rack3d-visualizer three

# pnpm
pnpm add rack3d-visualizer three

CDN (no build step)

<!-- Three.js peer dep (must load first) -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>

<!-- Rack3D UMD bundle -->
<script src="https://cdn.jsdelivr.net/npm/rack3d-visualizer/dist/rack3d-visualizer.umd.js"></script>

<!-- Global: window.Rack3D.Rack3DVisualizer -->

Quickstart

Three steps: define your container, build your rack JSON, instantiate.

1 — HTML

<!-- Give the visualizer a sized container -->
<div id="my-rack" style="width:100%;height:100vh"></div>

2 — ESM (bundler)

import { Rack3DVisualizer } from 'rack3d-visualizer';

const rackData = {
  name: 'PROD-RACK-01',
  units: 24,
  rackTemp: 38,          // °C  — rack-level sensor
  pduCapacity: 6400,     // W   — PDU rated capacity
  pduLoad: 3215,          // W   — current draw
  devices: [
    { id:'d1', name:'Core Router',  type:'router',   startUnit:1,  heightUnits:2, watts:450 },
    { id:'d2', name:'Firewall FW-1', type:'firewall', startUnit:3,  heightUnits:2, watts:320 },
    { id:'d3', name:'Switch 48p',    type:'switch',   startUnit:5,  heightUnits:1, watts:180 },
    { id:'d4', name:'Web Server',    type:'server',   startUnit:6,  heightUnits:2, watts:620 },
    { id:'d5', name:'DB Server',     type:'server',   startUnit:8,  heightUnits:4, watts:850 },
    { id:'d6', name:'NAS Storage',   type:'storage',  startUnit:13, heightUnits:3, watts:290 },
  ]
};

const viz = new Rack3DVisualizer('#my-rack', {
  theme: 'dark',
  camera: { azimuth: Math.PI, elevation: 0.15 },
  onSelect: (device) => console.log('Selected:', device),
  onChange: (data)   => console.log('Changed', data.rack.name),
});

viz.setData(rackData);
ESM

3 — CDN (no bundler)

const { Rack3DVisualizer } = Rack3D;  // UMD global
const viz = new Rack3DVisualizer('#my-rack', { theme: 'dark' });
viz.setData(rackData);

Options Reference

All options are optional and deeply merged over defaults. Pass them as the second argument to the constructor or call viz.setOptions() at any time.

Tip: All options can be updated at runtime via viz.setOptions({ ... }) — the scene re-renders immediately.

Top-level

OptionTypeDefaultDescription
themestring | Object'dark'Theme name ('dark', 'light', 'oled', 'warm', 'matrix') or a partial theme object merged with dark as base.
deviceTypesObject{}Merge custom device types into the registry. Each entry: { color, hex, label, icon }.
onSelectFunctionnullCalled with the clicked RackDevice object when a device is selected in 3D.
onChangeFunctionnullCalled with { rack } after any mutation (device add/edit/remove, name change, etc).
onReadyFunctionnullCalled with the Rack3DVisualizer instance once Three.js has fully initialised.

view

OptionTypeDefaultDescription
mode'3d' | '2d''3d'Start in full 3D render or flat 2D schematic diagram mode.
wireframebooleanfalseRender all geometry in wireframe on load.
showLabelsbooleantrueShow floating device labels on startup.
autoRotatebooleanfalseSlowly orbit the camera around the rack.
autoRotateSpeednumber0.003Radians per frame when autoRotate is enabled.
showToolbarbooleantrueShow the top header toolbar with mode/label/wire buttons.
allowDragDropbooleantrueEnable dragging devices in the unit map to reposition them.
allowEditbooleantrueAllow clicking devices to open the inline editor.
allowAddRemovebooleantrueShow add-device buttons and per-device remove button.
allowJsonEditbooleantrueShow the JSON editor panel button in the toolbar.

camera

OptionTypeDefaultDescription
fovnumber44Perspective field-of-view in degrees.
azimuthnumberMath.PIInitial horizontal orbit angle (radians). Math.PI points at the rack's front face.
elevationnumber0.15Initial vertical orbit angle (radians). 0 = level, 1.4 = top-down.
distancenumber | 'auto''auto''auto' = rack-height × 2.2. Pass a number for explicit distance.
minDistancenumber4Closest zoom-in distance (scroll wheel limit).
maxDistancenumber80Furthest zoom-out distance.
orbitSpeednumber0.0045Mouse drag orbit sensitivity.
zoomSpeednumber0.035Scroll wheel zoom sensitivity.

lighting

OptionTypeDefaultDescription
ambientIntensitynumber6.0Scene-wide ambient light intensity. Higher = no shadows anywhere.
ambientColornumber0xd0e8ffHex colour for ambient light (cool blue by default).
overheadIntensitynumber9.0Per-light intensity of overhead directional banks.
overheadCountnumber6Number of overhead light fixtures (2–12). More = uniform light.

rackGlowIntensitynumber6.0Internal rack PointLight that adds blue glow between devices.
exposurenumber2.8ACES tone-mapping exposure multiplier. Higher = brighter overall.

const myTheme = {
  css: {
    bg:     '#0d0018',
    accent: '#cc44ff',
    panel:  '#110020',
    border: '#2a1040',
    green:  '#aa44ff',
  },
  scene: {
    clearColor:       0x0a0015,
    ambientColor:     0xcc88ff,
    baseboardColor:   0x8800ff,
    stripEmissive:    18,
  },
  rack: {
    frameColor: 0x1a0030,
    postColor:  0x2a0050,
  }
};

viz.setTheme(myTheme);

Public API

All mutating methods return this for chaining.

Data

MethodReturnsDescription
setData(rackData)thisLoad or replace all rack data. Triggers a full 3D rebuild.
getData()RackDataDeep copy of the current rack state as a plain object.

Runtime mutations

MethodReturnsDescription
setTheme(theme)thisApply a theme by name string or partial theme object. Re-injects CSS and rebuilds scene.
setOptions(partial)thisDeep-merge any subset of options at runtime.
setMode('3d'|'2d')thisSwitch render mode. 2D shows a flat unit-map diagram instead of Three.js.
setWireframe(bool)thisToggle wireframe on all rack and device geometry.
setLabels(bool)thisShow or hide floating device labels without rebuilding the scene.

Camera

MethodReturnsDescription
setCameraAngle(az?, el?, dist?)thisAnimate camera to azimuth/elevation/distance. Pass undefined to leave unchanged.
resetCamera()thisReturn camera to defaults from options.camera.

Toolbar toggles

MethodDescription
toggleLabels()Toggle floating label visibility + button state.
toggleWire()Toggle wireframe + button state.
toggleMode()Toggle 3D ↔ 2D + button state.
toggleJson()Open / close JSON editor panel.
exportJson()Write current rack state to JSON editor textarea.
applyJson()Parse JSON editor content and hot-apply to rack.
destroy()Dispose Three.js renderer, remove DOM, unbind events. Call before unmounting.

Method chaining example

viz
  .setData(myRack)
  .setTheme('matrix')
  .setWireframe(false)
  .setCameraAngle(Math.PI, 0.2, 30)
  .setOptions({ view: { autoRotate: true } });

JSON Schema

The full shape of a rack data object. This is what you pass to setData() and what getData() returns.

{
  "rack": {
    "name":        "DC-RACK-01",   // Display name shown in header + sidebar
    "units":       24,            // Total rack unit capacity (4–48)

    // ── Rack-level sensors (not per-device) ──────────
    "rackTemp":    38,            // °C  — intake air / ambient temperature
    "pduCapacity": 6400,         // W   — PDU rated capacity
    "pduLoad":     3215,         // W   — current PDU load reading

    "devices": [
      {
        "id":          "d1",        // Unique string ID (any format)
        "name":        "Core Router",// Label shown in 3D, sidebar, unit map
        "type":        "router",    // Registered device type key
        "startUnit":   1,           // First rack unit occupied (1-indexed)
        "heightUnits": 2,           // Number of units tall (1U–12U)
        "watts":       450         // Power draw for this device (W)
        // Any extra fields are preserved through getData() / onChange()
      }
      // ... more devices
    ]
  }
}
Note: Temperature and PDU metrics are rack-level properties, not per-device. This reflects how real datacenter sensors work — a single intake thermistor and PDU clamp meter per rack.

React Integration

Use the provided React wrapper or mount the class directly in a useEffect.

Option A — React wrapper component

import RackViewer from 'rack3d-visualizer/examples/react/RackViewer';

function App() {
  const [theme, setTheme] = useState('dark');

  return (
    <div style={{ width:'100vw', height:'100vh' }}>
      <RackViewer
        data={rackData}
        theme={theme}
        options={{ view: { autoRotate: false } }}
        onSelect={dev => console.log(dev)}
      />
    </div>
  );
}

Option B — useEffect mount

import { useEffect, useRef } from 'react';
import { Rack3DVisualizer } from 'rack3d-visualizer';

export function RackEmbed({ data, theme = 'dark' }) {
  const ref = useRef(null);
  const viz = useRef(null);

  useEffect(() => {
    viz.current = new Rack3DVisualizer(ref.current, { theme });
    viz.current.setData(data);
    return () => viz.current.destroy();
  }, []);  // mount once

  useEffect(() => {
    if (viz.current) viz.current.setTheme(theme);
  }, [theme]);

  useEffect(() => {
    if (viz.current) viz.current.setData(data);
  }, [data]);

  return <div ref={ref} style={{ width:'100%', height:'100%' }} />;
}
Important: Always call viz.destroy() in the useEffect cleanup function to dispose the Three.js renderer and prevent memory leaks on unmount.
